WRITENOW FOR WINDOWS
by Jelte van Schelven

INSTALL
1. Right-click install.ps1 and choose "Run with PowerShell".
2. Start WriteNow from the Start menu or the desktop icon.

No administrator rights are needed. WriteNow opens in its own Microsoft Edge
window and appears under "Open with" for PDF files.

If Windows says that running scripts is disabled, open PowerShell in this
folder and type:
    powershell -ExecutionPolicy Bypass -File install.ps1

REMOVE
Right-click uninstall.ps1 and choose "Run with PowerShell".
This also removes documents saved inside WriteNow.

Full guide: https://github.com/jeltevanschelven8-afk/writenow/blob/main/docs/INSTALL.md
