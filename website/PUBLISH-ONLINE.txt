PUBLISH WRITENOW ONLINE (free)

This folder is the complete website. Just upload the folder.
This text file may come along; it does nothing.

EASIEST: NETLIFY
1. Go to  app.netlify.com/drop  and create a free account
   (with your e-mail or Google account).
2. Drag the whole "website" folder onto the page.
3. After a few seconds you get an address, for example
   https://happy-name-123.netlify.app
4. Nicer address: Site configuration > Change site name,
   for example "writenow". It then becomes
   https://writenow.netlify.app  (if that name is still free).
5. New version? Drag the new folder into Deploys again.

ALTERNATIVES
- Cloudflare Pages (pages.dev): dash.cloudflare.com > Workers & Pages >
  Create > Pages > Upload assets > upload the folder.
- GitHub Pages (github.io): create a new repository, upload the files, then
  Settings > Pages > Branch: main > Save.

INSTALL AS AN APP (for anyone with the address)
- Mac (Safari, macOS 14 or newer): File > Add to Dock.
- Windows (Edge or Chrome): the install icon at the right of the address bar,
  or menu > Apps > Install this site as an app. After that "WriteNow" also
  shows up for PDFs under "Open with".
- iPhone/iPad: Share button > Add to Home Screen.
